# Ринат — демо-сайт ведущего мероприятий

Демонстрационная версия сайта для клиента. Структура повторяет страницу-образец `kidshubentertainment.com/experience`:
центральный персонаж, вокруг которого вращаются «планеты»-разделы, и конструктор мероприятия с мгновенным расчётом стоимости.

## Что есть

- **Главная «Вселенная событий»** (`index.html`): Ринат в центре, 8 планет на орбите (Свадьбы, Корпоративы, Дни рождения,
  Выпускные, Конференции, Шоу и артисты, Калькулятор, Спросить ассистента). Ниже секции-заготовки: обо мне, услуги,
  портфолио, отзывы, FAQ, контакты.
- **Страницы услуг** (`index.html#/wedding`, `#/corporate` и т. д.): описание, что входит, этапы работы, FAQ, переход в калькулятор.
- **Калькулятор мероприятия** (`calculator.html`): выбор площадки и формата, затем вкладки «Детали», «Ведущий», «Музыка и техника»,
  «Шоу-программа», «Интерактив», «Фото и видео», «Декор» и «Площадка» (если площадка не выбрана). Итог пересчитывается сразу,
  в конце — смета и форма заявки.
- **Ассистент** — окно чата на всех страницах. Сейчас отвечает шаблонами по ключевым словам (демо), ИИ подключается позже.

Заявки и чат **никуда не отправляются** — это заглушки для показа клиенту.

## Как поменять цены и тексты

Всё в одном файле — `assets/js/data.js`:

- `SITE` — телефон, ссылки на мессенджеры, стоимость доп. часа;
- `SERVICES` — тексты страниц услуг;
- `CALC.eventTypes` — базовая стоимость ведения и включённые часы;
- `CALC.tabs` — все услуги калькулятора. Поле `unit`: `fixed` — фикс, `hour` — за час, `guest` — за гостя,
  `unit` — за штуку, `table` — за стол (гости / 8), `tier` — по числу гостей, `quote` — «от», под расчёт.

## Локальный запуск

Сборка не нужна — это статичный сайт.

```bash
npx http-server -p 8080 .
# открыть http://localhost:8080
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → выбрать ветку с сайтом и папку `/ (root)` → Save.
Через 1–2 минуты сайт будет доступен по адресу `https://<владелец>.github.io/rinattest/`.
